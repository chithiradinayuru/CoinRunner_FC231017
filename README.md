# 🎮 Coin Runner – Unity 2D Platformer

## 📌 Project Description
Coin Runner is a 2D platformer game developed using Unity. The player controls a character, collects coins, avoids hazards, and reaches the goal to complete the level.

This project was created as part of a Unity game development lab exercise to practise basic 2D game development concepts.

## 🕹️ Game Features
- **Player Movement:** Move left and right.
- **Jumping:** Jump across platforms and obstacles.
- **Coin Collection:** Collect coins throughout the level.
- **Coin Counter:** Track the number of coins collected.
- **Hazards:** Avoid spikes and other dangerous areas.
- **Camera Follow:** The camera smoothly follows the player.
- **Win Condition:** Reach the goal to complete the level.
- **Restart Option:** Restart the level after completion.

## 🛠️ Technologies Used
- Unity
- C#
- Unity 2D Physics
- Tilemap
- TextMesh Pro
- Git and GitHub

## 📂 Project Structure
- `Assets/` – Game scenes, scripts, prefabs, and other game assets.
- `Packages/` – Unity package dependencies.
- `ProjectSettings/` – Unity project configuration files.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open Unity Hub.
3. Click **Add** or **Open** and select the downloaded project folder.
4. Open the project using a compatible Unity Editor version.
5. Open the main game scene from the `Assets` folder.
6. Press the **Play** button in Unity to run the game.

## 🎯 How to Play
- Use the **Left Arrow / A** keys to move left.
- Use the **Right Arrow / D** keys to move right.
- Press **Space** to jump, if configured in the game controls.
- Collect coins to increase your score.
- Avoid spikes and other hazards.
- Reach the goal to complete the level.
